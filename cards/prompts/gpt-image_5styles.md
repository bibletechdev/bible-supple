# GPT Image 用プロンプト集（5スタイル）

題材：御霊の実（ガラテヤ5:22-23）「9つの実がなる一本の木」
共通ルール：
- 文字は入れない（聖句はCanvaで重ねる）
- 縦長 2:3（ポストカード 100×148mm に近い）
- 下 1/3 は聖句を置く余白として、要素を少なくする
- 1枚目ができたら、それを添付して「同じ画風で、題材を〇〇に変えて」と頼むとシリーズの統一感が出る

---

## 共通の末尾（毎回コピーして付ける）
```
縦長 2:3 のポストカード用イラスト。文字・ロゴ・透かしは一切入れない。
画面の下 1/3 は、あとから聖句の文章を載せるために背景をシンプルにして余白を残す。
高解像度、印刷向け、色は落ち着いたトーン。
```
```
Portrait 2:3 postcard illustration. Absolutely no text, letters, logos or watermarks.
Keep the bottom third simple and uncluttered as negative space for a Bible verse to be added later.
High resolution, print-ready, calm and refined palette.
```

## 題材の差し替え例（「一本の木、9つの果実」の部分を置き換える）
| 聖句 | 差し替える題材 |
|---|---|
| 1コリント13 愛の章 | 中心に小さな灯火、周りに15枚の花びらが放射状に開く花 |
| エペソ6 神の武具 | 兜・胸当て・盾・剣・帯・靴が空中に浮かんで並ぶ静物 |
| ヨハネ15 ぶどうの木 | 太い幹から伸びる枝と、たわわなぶどうの房 |
| ヨハネ11:25 よみがえり | 朝日に照らされた、石が転がされた空の墓 |
| マタイ11:28 重荷 | 道端に置かれた重い荷物と、その先に続く光の道 |
| ルカ2 降誕 | 星の下の飼い葉桶、遠くの羊飼いと羊 |

## うまくいかない時
- 果実が9つにならない → 「9つ」を「9 clearly separated fruits, count them」と強調、または画像を添付して「果実を9つに直して」と修正指示
- 文字が入る → 「no text」を先頭にも入れる。それでも入るなら Canva で塗りつぶす
- 画風がバラける → 1枚目を必ず添付して「この画風を維持」と書く
