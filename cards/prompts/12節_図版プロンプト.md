# 第1弾 12節 図版プロンプト（題材ごと）

`gpt-image_5styles.md` の「共通の末尾」と「5スタイル」に、下の題材を差し込んで使う。
画風は5スタイルから1つ選んで12枚すべて同じにする。1枚目を添付して「この画風を維持して、題材を〇〇に」と頼むと揃う。
完成した図版は `images/<id>.jpg`（縦 2:3、長辺 2000px 前後）に保存すればページに反映される。

## 使い方
1. スタイル文（例：①手書き風）を貼る
2. 下の「題材」の文を貼る
3. 「共通の末尾」を貼る
4. 生成 → 文字が入っていないか、下1/3に余白があるかを確認
5. Canva で聖句（口語訳）を下1/3に重ね、`images/<id>.jpg` で書き出す

## 励まし

### phil-4-6-7 ── ピリピ4:6-7「思い煩うな、祈れ」
```
題材：夜明け前の静かな部屋の窓辺。窓の外に淡い朝焼け、窓台に一本のろうそくと、ほどけた紐のように軽くなった糸くずが風に浮いている。
締めつけていたものがほどけて、平安が入ってくる情景。人物は入れない。
```
```
Subject: A quiet room at dawn, a single candle on the windowsill, pale sunrise outside the window. A tangled knot of thread has loosened and drifts weightlessly in the air, as if worry has been untied and peace is coming in. No people.
```

### matt-11-28 ── マタイ11:28「重荷を負う者よ、来なさい」
```
題材：道端に下ろされた古い大きな旅の荷物（麻袋と革のかばん）。その先に、木漏れ日が差す緩やかな坂道が続き、道の先が柔らかい光に溶けている。
「もう背負わなくていい」という安堵。人物は入れない。
```
```
Subject: A heavy old traveler's burden (burlap sack and leather bag) set down at the roadside. Beyond it a gentle uphill path dappled with sunlight through trees, the far end dissolving into soft light. A feeling of relief, of not having to carry it anymore. No people.
```

### rom-8-28 ── ローマ8:28「万事を益とする」
```
題材：織り機にかかった織物を裏側から見た構図。裏はもつれた糸だらけだが、めくれた一角から表面が見え、そこには美しい模様（一輪の花か星）が織り上がっている。
「今は分からなくても、神は良い模様を織っている」ことを表す。人物は入れない。
```
```
Subject: A tapestry on a loom seen from the back, a chaos of tangled, knotted threads. One corner is folded over to reveal the front side, where a beautiful pattern (a single flower or a star) is being woven. All things being woven together for good. No people.
```

```

Subject: A tiny seedling with two fresh leaves emerging from dark soil. Above it, a faint translucent vision of the same plant fully grown and in bloom overlaps the sky. Morning light, dew drops. Beginning and completion in one frame. No people.
```

```
愛の15の性質を表す。左右対称で、結婚祝いにふさわしい端正な構図。人物は入れない。
```
```
Subject: A small flame from an oil lamp at the center, surrounded by a single large flower with fifteen petals opening radially, each petal a slightly different hue. Symmetrical, elegant composition suitable for a wedding card. No people.
```

## Canva で聖句を重ねるときの目安
- フォント：明朝（Noto Serif JP / しっぽり明朝）。本文 1.0〜1.1倍、出典は小さく
- 位置：下 1/3 の余白に中央揃え。本文の上下に 1 行分の空き
- 色：図版の暗い部分なら白、明るい部分なら濃い茶（#2b2a27）。金（#b48a3c）は出典行だけ
- 出典表記：「ヨハネによる福音書 11:25（口語訳）」の形で統一
- 書き出し：JPG、品質 90、幅 1400px 以上 → `images/<id>.jpg`
